# Guide pdoc3

## 🚀 Documentation moderne sans complexité

**pdoc3** remplace pydoc avec un CSS magnifique intégré.

## ⚡ Commandes essentielles

```bash
# Serveur développement (recommandé)
pdoc --http :8080 main utils.config

# Génération HTML statique
pdoc --html -o docs/html main report_manager
```

## 🎨 Avantages pdoc3

- ✅ CSS moderne intégré
- ✅ Syntaxe highlighting automatique  
- ✅ Navigation interactive
- ✅ Zero configuration
- ✅ Serveur intégré

## 📖 Accès

**Serveur** : http://localhost:8080  
**Modern et rapide !**
