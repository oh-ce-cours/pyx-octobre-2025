# Documentation pydoc - Méthode simplifiée

## 🚀 Démarrage en 1 commande

```bash
# Depuis la racine du projet
cd /path/to/demo_api
python -m pydoc -p 3000
```

## 🌐 Accès immédiat

- **Documentation complète** : http://localhost:3000
- **Module spécifique** : http://localhost:3000/main
- **Recherche** : http://localhost:3000/?key=main

## ✅ Avantages de cette méthode

1. **Aucun script complexe** - Une seule commande
2. **CSS intégré** - Styles par défaut fonctionnels
3. **Navigation automatique** - Liens entre modules
4. **Recherche intégrée** - Fonctionnalité de recherche
5. **Recherche permanente** - Pas de fichiers à regénérer

## 🔧 Commandes utiles

```bash
# Port personnalisé
python -m pydoc -p 8080

# Documentation d'un module spécifique
python -m pydoc main

# Documentation HTML d'un module (fichier)
python -m pydoc -w main

# Aide complète
python -m pydoc -h
```

## 💡 Conclusion

**Utilisez `python -m pydoc -p 3000` plutôt que nos scripts complexes !**
